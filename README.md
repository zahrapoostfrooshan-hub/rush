# Shop Rush 2 | Erfan Edition

A lightweight 3D supermarket-management game built with Vite, Three.js, and Electron.
The opening screen contains an animated intro dedicated to **عرفان (Erfan)**.

## Run in a browser

Requirements: Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Run as a desktop app during development

```bash
npm install
npm run electron:dev
```

## Build the web version

```bash
npm run build
```

## Build Windows EXE locally

On Windows:

```bash
npm install
npm run dist:win
```

The `release/` folder contains a Windows installer and a portable EXE.

## Build with GitHub Actions

1. Create an empty GitHub repository.
2. Upload/push all files in this folder to the repository's `main` branch.
3. Open the repository's **Actions** tab and choose **Build Shop Rush 2 for Windows**.
4. Click **Run workflow** (or push to `main`).
5. When the workflow finishes, open its run and download **Shop-Rush-2-Windows** under **Artifacts**.

The artifact includes the Windows installer and portable executable generated by Electron Builder.

## Controls

- WASD or arrow keys: move
- Drag the mouse: rotate the camera
- Escape or the pause button: pause
- Dashboard buttons: restock, upgrade, hire, save
- FA / EN button: switch language

## Included in this first playable foundation

- Animated Erfan Edition intro screen
- Lightweight low-poly 3D supermarket scene
- Third-person player movement and mouse camera
- Customers with simple shopping, checkout, and exit phases
- Product shelves and stock counter
- Separate warehouse room with storage crates
- Basic money, sales, restocking, upgrade, and hiring actions
- Persian and English interface
- Local save/load using browser storage
- Electron desktop packaging and Windows GitHub Actions workflow

## Current development stage

This is a playable first foundation, not the finished full-scale game. Advanced customer queue logic, employee pathfinding and automatic restocking, richer collisions, more products, and deeper store expansion are planned for later stages.
